SG Estetal · Redaktion

Website pflegen
in fünf Schritten

So pflegst du News, Mannschaften, Termine und alle weiteren Inhalte der Website selbst.

1

Einladung in der E-Mail

Du bekommst eine E-Mail mit dem Betreff Join „blubbernase/estetal“ on Pages CMS. blubbernase ist der Benutzername von Nelson Baptista — die Einladung ist also echt.

2

Auf den Link klicken

In der E-Mail auf Join „blubbernase/estetal“ klicken. Falls der Link nicht funktioniert: die darunter stehende Adresse kopieren und in den Browser einfügen.

3

Code bestätigen

Anschließend wird ein Code an deine E-Mail-Adresse geschickt. Diesen Code eintragen — fertig. Ein Passwort brauchst du nicht. Danach siehst du das Projekt estetal.

4

Inhalt bearbeiten

Links in der Leiste stehen alle Bereiche: News, Mannschaften, Termine, Ehrenamt und so weiter. Klick den Bereich an, den du pflegen willst. Zum Ändern einfach in die Felder schreiben — für einen neuen Eintrag nach unten scrollen und Add an item klicken.

5

Speichern

Oben rechts auf Save klicken. Fertig. Die Änderung steht nach etwa einer Minute auf sg-estetal.de — Seite ggf. neu laden.

Layout, Farben oder neue Bereiche? Alles, was über das Pflegen von Inhalten hinausgeht, macht Nelson Baptista — sprich ihn einfach an.
Keine Angst vor Fehlern. Jede Änderung wird gespeichert und lässt sich zurückholen — es kann nichts endgültig kaputtgehen. Im Zweifel lieber speichern und nachfragen als gar nicht trauen.
